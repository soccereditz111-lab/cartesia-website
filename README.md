# Cartesia Website

Official website for Cartesia — modern websites and local visibility systems for traditional local businesses.

## Stack
- Next.js 14 (App Router)
- Tailwind CSS
- Deployed on Vercel

## Local development
```bash
npm install
npm run dev
```

## Design system
- Background: pure black
- Accent: yellow → orange → red gradient (from logo)
- Clean, simple, high-contrast, no heavy geometric decoration
